# Resistor & Circuit Calculator (C++) ⚡

A C++ Command-Line Tool designed for electronics and mechatronics applications. It helps engineers and students decode resistor values from color bands, solve complex resistor circuits (Series/Parallel), and apply Ohm's Law.

## 🌟 Key Features
- **Resistor Color Code Decoder:** Supports 4-band, 5-band, and 6-band resistors with tolerance values.
- **Circuit Equivalent Resistance Calculator:** Calculates total resistance for complex circuits with multiple branches (Series & Parallel logic).
- **Ohm's Law Solver:** Easily computes Current , Voltage , or Resistance .
- **Interactive CLI:** Built-in loop allowing multiple continuous calculations.

## 🛠️ Built With
- **Language:** C++
- **Domain:** Mechatronics / Electronics Engineering
